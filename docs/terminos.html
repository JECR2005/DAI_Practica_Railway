Condiciones del Servicio

Última actualización: 15 de octubre de 2026 • Aplicación: Agente de Soporte con IA (DAI Práctica 2)

1. Aceptación de las Condiciones

Al autorizar el acceso, instalar o interactuar con el Agente Inteligente de Soporte al Cliente (en adelante, «el Servicio» o «la Aplicación»), usted acepta cumplir estas Condiciones del Servicio y todas las leyes aplicables. Si no está de acuerdo con alguno de estos términos, le solicitamos no utilizar el Servicio ni autorizar permisos a través de su cuenta de Google.

2. Descripción del Servicio

El Servicio consiste en un agente automatizado desarrollado en Python que procesa registros de texto contenidos en una hoja de cálculo de Google Sheets. A través del modelo de lenguaje Google Gemini AI, el sistema:

  • Clasifica comentarios o tickets por departamento (Soporte Técnico, Facturación, Ventas, Logística, etc.).
  • Realiza análisis de sentimiento del texto (Positivo, Negativo, Neutro).
  • Escribe de forma autónoma los resultados en la misma hoja de cálculo para facilitar la gestión al equipo humano.

El Servicio puede ejecutarse de manera periódica utilizando flujos de trabajo de GitHub Actions o de forma local mediante línea de comandos.

3. Uso Autorizado y Responsabilidades del Usuario

Usted como usuario se compromete a:

  • Proporcionar acceso únicamente a hojas de cálculo sobre las cuales tenga autorización legítima de lectura y escritura.
  • No utilizar el Servicio para procesar contenido ilícito, difamatorio, que vulnere derechos de autor o que infrinja las políticas de uso aceptable de Google.
  • Mantener la confidencialidad de sus credenciales, archivos client_secrets.json y claves de API personales.

4. Servicios de Terceros y APIs

El Servicio interactúa con plataformas de terceros sujetas a sus propios términos y políticas:

  • Google Cloud Platform & Google Sheets API: Sujetos a las condiciones de servicio de Google Cloud.
  • Google Gemini AI: Sujeto a las políticas de uso de servicios generativos de inteligencia artificial de Google.
  • GitHub / GitHub Actions: Plataforma de alojamiento de código e integración continua.

No nos hacemos responsables por interrupciones, cambios en cuotas de uso o suspensión de servicios por parte de dichos proveedores externos.
