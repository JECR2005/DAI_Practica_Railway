Privacidad y Seguridad

Política de Privacidad

Última actualización: 15 de octubre de 2026 • Aplicación: Agente de Soporte con IA (DAI Práctica 2)

1. Introducción

Esta Política de Privacidad describe cómo el Agente Inteligente de Soporte al Cliente (en adelante, «la Aplicación») recopila, utiliza, procesa y protege la información cuando usted autoriza el acceso mediante los servicios de Google Cloud Platform y OAuth 2.0.

La Aplicación es un proyecto académico y funcional desarrollado para la materia de Diseño con Agentes de Inteligencia Artificial (DAI), enfocado en automatizar la clasificación de quejas de clientes y análisis de sentimientos mediante modelos de lenguaje (Gemini AI) y hojas de cálculo de Google Sheets.

2. Información que recopilamos y permisos solicitados

Para su funcionamiento, la Aplicación solicita acceso mediante OAuth 2.0 a los siguientes alcances (scopes) de la API de Google:

  • https://www.googleapis.com/auth/drive y/o https://spreadsheets.google.com/feeds: Permite acceder únicamente a la hoja de cálculo designada por el usuario (por ejemplo, "Respuestas de Quejas (Base de Datos)") para leer las quejas ingresadas y registrar las etiquetas de clasificación, sentimiento y fecha de procesamiento.
Principio de Privilegio Mínimo: La Aplicación solo interactúa con la hoja de cálculo explícitamente configurada. No lee correos personales, archivos privados no vinculados de Google Drive ni información personal ajena a dicha hoja.

3. Cómo utilizamos sus datos

Los datos obtenidos de la hoja de cálculo se utilizan estrictamente para:

  1. Identificar registros pendientes de atención (filas no procesadas).
  2. Enviar el texto de la queja a la API de Google Gemini (modelo gemini-2.5-flash o superior) para determinar el departamento adecuado (ej. Soporte Técnico, Ventas, Logística) y el sentimiento (Positivo, Negativo, Neutro).
  3. Actualizar las columnas correspondientes en su hoja de cálculo con los resultados obtenidos.

No vendemos ni comercializamos sus datos bajo ninguna circunstancia. La información no se utiliza para fines publicitarios ni para entrenar modelos de terceros sin autorización.

4. Declaración de Política de Datos de Usuario de las API de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida a través de las API de Google se adhieren a la Política de Datos de Usuario de los Servicios de las API de Google , incluidos los Requisitos de Uso Limitado (Limited Use Requirements).

5. Almacenamiento, retención y seguridad

La Aplicación se ejecuta de manera automatizada en entornos de ejecución temporal (GitHub Actions o entornos locales autorizados).

  • Sin base de datos externa: No mantenemos servidores de base de datos externos que almacenen permanentemente el contenido de sus hojas. Toda la persistencia permanece en su propia cuenta de Google Sheets.
  • Procesamiento en memoria: Los textos de las consultas son procesados en memoria durante el ciclo de ejecución y descartados una vez devuelta la respuesta a Google Sheets.
  • Credenciales seguras: Las claves de API y secretos de autenticación se gestionan mediante variables de entorno encriptadas (GitHub Secrets / archivos .env locales protegidos por .gitignore).

6. Revocación de permisos y control del usuario

El usuario conserva el control absoluto de sus datos en todo momento. Puede revocar el acceso de esta aplicación a su cuenta de Google en cualquier momento ingresando a:

https://myaccount.google.com/permissions
Seleccione la aplicación y haga clic en "Quitar acceso". A partir de ese momento, la Aplicación no podrá volver a conectarse con sus hojas de cálculo.

7. Contacto

Si tiene dudas, solicitudes de aclaración o comentarios relacionados con esta Política de Privacidad o el tratamiento de datos de la Aplicación, puede ponerse en contacto con el equipo del proyecto a través del repositorio oficial de GitHub:
